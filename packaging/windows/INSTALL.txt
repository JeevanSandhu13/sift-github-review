SIFT FOR WINDOWS
================

Before you install
------------------
This Windows beta is not yet signed with a public Authenticode certificate.
Windows Defender SmartScreen may therefore display "Windows protected your
PC." Check the published SHA-256 checksum before selecting More info > Run
anyway. If Smart App Control or an organization-managed policy blocks unsigned
software, leave that protection enabled and wait for a signed release.

Sift supports 64-bit Windows 11, build 22000 or newer. It also needs Microsoft
Edge WebView2 Runtime 86.0.616.0 or newer, which is normally included with
Windows 11. If the runtime is missing or outdated, the installer stops without
changing the computer and directs you to Microsoft's official download.

Install Sift
------------
1. Run Sift-Windows-x64-Setup.exe.
2. Follow the per-user installer. Administrator access is not required.
3. Open Start > Sift > Sift.

The portable download is an alternative for systems where software is deployed
without an installer. Extract the entire Sift-Windows-x64.zip archive to a
writable local folder, then run Sift.exe. Do not copy Sift.exe out of its folder;
the adjacent _internal directory contains required application files.

Your data and settings
----------------------
Sift does not include a model account. Connect your own provider account or
local model from Manage providers.

Credentials are stored in Windows Credential Manager, not in Sift's settings
files. Imported sessions are stored in %USERPROFILE%\.sift-sessions. A folder
opened in place keeps its private Sift state in that folder's .sift directory.
Redacted diagnostic logs are stored in %LOCALAPPDATA%\Sift\Logs. Sift contacts
the update service only when you ask it to check for an update.

Institutional policy
--------------------
Administrators can provide a protected policy file at:

  %ProgramData%\Sift\enterprise_policy.yaml

The policy can restrict model providers, data connections, disclosure,
destinations, diagnostics, exports, and resource limits. If a configured policy
is invalid, Sift does not start the affected operation. Most users do not need
this file.

Troubleshooting
---------------
If Sift does not open, confirm that you installed the x64 build on Windows 11
and that WebView2 is current. For a portable installation, extract the full
archive instead of moving Sift.exe by itself.

The following PowerShell commands run local checks without reading research
data or saved credentials:

  & "$env:LOCALAPPDATA\Programs\Sift\Sift.exe" --platform-check
  & "$env:LOCALAPPDATA\Programs\Sift\Sift.exe" --credential-store-check

The platform check covers the renderer, bundled assets, 64-bit runtime,
credential integration, and AppContainer confinement. The credential check
writes, reads, and removes a temporary test value in Windows Credential
Manager.

Uninstall Sift
--------------
Open Windows Settings > Apps > Installed apps, find Sift, and select Uninstall. The
uninstaller removes the application and shortcuts but keeps research sessions,
project .sift directories, logs, and credentials. Use Manage providers > Forget
before uninstalling, or remove Sift entries from Windows Credential Manager, if
you also want to delete saved credentials.
